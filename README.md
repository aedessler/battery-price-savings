# Battery price-savings — figure code

Code that reproduces every figure in the battery price-savings manuscript
(the anchored bid-stack counterfactual for ERCOT and CAISO). This repository
holds the figure scripts (`Fig1.py`–`Fig6.py`), the analysis and
data-download modules they depend on, the LOWESS helper (`core.py`,
`config.py`), and the two hourly master input series under `data/`.

Each figure script is standalone — `python Fig6.py` — and writes
`figN_<name>.jpg` into this folder. Figs 2–3 first produce their PNG in
`./figs/` via `scarcity_price.validation_figure`, then re-encode it here.

| Fig | Script | Output |
|-----|--------|--------|
| 1 | `Fig1.py` | `fig1_anchor.jpg` — the anchored counterfactual, one ERCOT hour |
| 2 | `Fig2.py` | `fig2_scarcity_fit_ercot.jpg` |
| 3 | `Fig3.py` | `fig3_scarcity_fit_caiso.jpg` |
| 4 | `Fig4.py` | `fig4_diurnal.jpg` — hourly price impact by market/year |
| 5 | `Fig5.py` | `fig5_monthly.jpg` — monthly savings, central + month-max |
| 6 | `Fig6.py` | `fig6_stacks.jpg` — CAISO evening supply stacks, wall/drop annotated |
| 7 | — (hand-drawn) | `fig7_schematic.png` — where each market sits on the curve |

## Layout and dependencies

The figure scripts import six analysis modules that now live in this folder:
`dam_counterfactual.py` (ERCOT DAM downloader + stack builder),
`caiso_dam_counterfactual.py` (CAISO processor + stack builder),
`annual_savings.py`, `scarcity_price.py`, `stack_counterfactual.py`, and
`dam_monthly_savings.py`. Two more download/process scripts are here too:
`download_caiso_bids.py` (CAISO OASIS bid downloader) and
`caiso_storage_bids.py`. The LOWESS helper `core.py`/`config.py` is local (no
external package needed). `_common.py` puts this folder on `sys.path` and holds
the shared colours, the cached hourly-data loader, and `FLOOR_CI`.

Data lives under `data/`:
- **Masters (tracked, shipped with the repo):**
  `data/ercot/complete_ercot_2020_2025.csv`,
  `data/caiso/complete_caiso_2020_2025.csv` — hourly price/load/generation
  series, 2020–2025. These are the only non-rebuildable inputs.
- **Working data (gitignored, re-downloadable):** ERCOT DAM parquets in
  `data/dam/`, per-hour caches in `data/annual/`, CAISO bids in
  `data/caiso/pub_bids/`, ERCOT stack-fig inputs in
  `data/stack_counterfactual/`. Rebuild via the download/process scripts (see
  Reproduction). On the original author's machine these resolve to a sibling
  `../data/`; a fresh clone regenerates them into a local `data/`.

## Reproduction

Figs 2 and 3 (the empirical scarcity-price fits) and the static Fig 7 build
from a bare clone with no extra data. The rest need the re-downloadable working
data:

```
pip install -r requirements.txt
export GRIDSTATUS_API_KEY=...     # only for the ERCOT/stack downloads;
                                  # CAISO bids need no key
```

1. Download the raw working data: run the download entry points in
   `dam_counterfactual.py` (ERCOT DAM 60-day disclosure) and
   `download_caiso_bids.py` / `caiso_dam_counterfactual.py` (CAISO OASIS bids),
   and `stack_counterfactual.py` (Fig 1 inputs).
2. Build the per-hour cache: `python annual_savings.py` (its `compute()` writes
   `data/annual/v<N>/<market>/*.parquet`, where `<N>` is `CACHE_VERSION`; pass
   `--force` to rebuild).
3. Generate the figures: `python Fig1.py` … `python Fig6.py`.

The GridStatus key is read only from the `GRIDSTATUS_API_KEY` environment
variable — it never appears in the code or in any committed file.

## Tests

Two standalone modules cover the numerics that feed the reported figures and
tables — the production-cost stack integral, the price/anchor lookups, and the
step-plot coordinates:

```
python tests/test_integral.py       # stack integral (segment traversal, caps)
python tests/test_stack_lookup.py   # price_np, anchor edges, step_xy
```

Each runs standalone as shown, or under `pytest` if it is installed.

## Notes

- **Figure 7 is a hand-drawn schematic**, not generated by a script.
  `fig7_schematic.png` is the export embedded in the manuscript. Its editable
  Keynote source (`.key`) is kept out of this repo (gitignored).
- **Figure numbering changed in V4.** Relative to V3: the old annual-range
  Fig. 6 and the headroom Fig. 8 were both dropped from the paper, the CAISO
  supply-stacks figure moved from Fig. 7 to **Fig. 6**, and the new schematic
  is **Fig. 7**. The dropped figures and their scripts are in `archive/`
  (`Fig6_annual_range.py` + `fig6_annual_range.jpg`; `Fig8_headroom.py` +
  `fig8_headroom.jpg` + `Fig8_headroom.parquet`).
- **The headroom cache is preserved.** `archive/Fig8_headroom.parquet`
  (~35,000 hours, ~30 min to rebuild) still holds the per-hour wall/drop
  distances quoted in the text, even though the figure itself is gone.
  `archive/Fig8_headroom.py` reads it; pass `--force` to recompute.
- **`FLOOR_CI` in `_common.py` is cached**, not recomputed. These are the
  month-max bootstrap intervals from `annual_savings.bootstrap_ci`
  (2026-07-18). Re-run that function if the underlying hourly caches change.
  (Only used by the archived annual-range script now.)
- `archive/` also holds earlier superseded work: `make_ms_figs.py` (Figs 4–6
  were split out of it), `make_battery_bids_fig.py`, `build_manuscript.py`'s
  outputs, `orig_fig_netload.png` (the removed net-load figure), and
  `ms_fig_stacks_two_panel.png` (the two-panel ERCOT+CAISO variant that was
  dropped in favour of the single-panel Fig. 6).

## Verification

The generated figures are built from this folder (the code was first relocated
out of `bidstack/` to the repo root on 2026-07-20, where each figure then
reproduced its V4 embed byte-for-byte). Figs 1–5 follow the same analysis as
**V4**; Fig. 6's supply stacks were subsequently corrected to draw
left-continuous steps (`where="pre"`), so `fig6_stacks.jpg` here supersedes the
image embedded in V4. The production-cost integral fix in `annual_savings.py`
changes the reported production-cost numbers (ERCOT $92M/$281M, CAISO
$486M/$651M for 2024/2025) but not the consumer-savings figures. Fig. 7 is a
manual export, so `fig7_schematic.png` here is the exact PNG lifted from the V4
package.
